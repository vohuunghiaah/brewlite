# BrewLite – Task 3.1 Architecture Decision Records

Thư mục `adr/` chứa các quyết định kiến trúc được đề xuất cho Task 3.1.

## Danh sách

1. `001-modular-monolith.md` – Kiến trúc Backend Modular Monolith.
2. `002-postgresql-migration.md` – PostgreSQL và Migration.
3. `003-mock-payment.md` – Dịch vụ thanh toán mô phỏng.
4. `004-logging-healthcheck.md` – Logging và Health Check.
5. `005-configuration-management.md` – Quản lý cấu hình.

## Lưu ý

Các ADR có trạng thái `Proposed` hoặc nội dung mô tả thiết kế cần được cập nhật thành `Accepted`/`Implemented` chỉ sau khi nhóm thống nhất và triển khai thực tế. Nội dung trong các file là quyết định/đề xuất kiến trúc, không tự động chứng minh rằng chức năng đã có trong mã nguồn.
